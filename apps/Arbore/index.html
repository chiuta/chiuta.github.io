Cum se calculează

Lista este construită din locurile introduse în evenimente. Nu există hartă: nicio cerere către servicii externe.

Confidențialitate și stocare

Datele de familie sunt sensibile. Arborele este păstrat doar în acest browser (localStorage/IndexedDB), nu există conturi, analiză sau trimitere de date. Exporturile se salvează doar pe dispozitivul tău.

Criptare locală (opțional)

Cu parolă, arborele salvat în browser este criptat AES-GCM 256 (cheie derivată cu PBKDF2-SHA256, 310 000 iterații).

Atenție: dacă pierzi parola, datele criptate nu mai pot fi recuperate de nimeni, inclusiv de autor. Păstrează și o copie de rezervă.

Import

Se acceptă GEDCOM 5.5.1 UTF-8; ANSEL/ANSI sunt tratate minimal, cu avertisment. Fișierele cu probleme sunt importate cât se poate, cu raport de erori.
